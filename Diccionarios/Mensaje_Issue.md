# 📢 Reportar Issue en GitHub

## ¿Qué estás a punto de hacer?

Vas a crear un **reporte público** en el repositorio de GitHub del proyecto. Este reporte será visible para:
- ✅ El desarrollador del proyecto


## Tipos de Reportes

### 🐛 **Bug (Error)**
Usa esta opción cuando:
- La aplicación se cierra inesperadamente
- Aparecen errores al realizar acciones
- Alguna funcionalidad no funciona como debería
- Los datos no se guardan correctamente

**Importante**: Si reportas un bug, puedes adjuntar el archivo de log del día para ayudar a diagnosticar el problema más rápido. Se recomienda adjuntarlo.

### 💡 **Sugerencia (Mejora)**
Usa esta opción cuando:
- Tienes ideas para mejorar la aplicación
- Quieres proponer nuevas funcionalidades
- Sugieres cambios en la interfaz o flujo de trabajo
- Detectas algo que podría ser más eficiente

## ⚠️ Consideraciones Importantes

1. **Privacidad**: 
   - NO incluyas información confidencial de clientes
   - NO compartas datos sensibles de tu empresa

2. **Claridad**:
   - Describe el problema o sugerencia de forma clara
   - Incluye pasos para reproducir el error (si es un bug)
   - Añade capturas de pantalla si ayudan a explicar
   

## ✅ ¿Continuar?

Al aceptar, se abrirá el formulario de reporte donde podrás:
- Elegir el tipo de reporte (Bug o Sugerencia)
- Escribir una descripción detallada
- Adjuntar archivos de log (solo para bugs)
- Publicar directamente en GitHub
