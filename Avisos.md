# Bienvenido al Sistema de Gestión de Expedientes

Este es un mensaje de ejemplo que el administrador puede personalizar.

## Funcionalidades

El administrador puede:

- Modificar este mensaje desde el menú **Admin → Administrar Avisos**
- Activar o desactivar la visualización del aviso
- Usar formato Markdown para dar formato al texto

### Formato Markdown Soportado

Puedes usar:
- **Títulos** con # (uno o más)
- **Listas** con - o *
- **Texto normal** como este
